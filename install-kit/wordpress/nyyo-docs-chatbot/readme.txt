Embed a Nyyo docs chatbot via shortcode [nyyo_docs_chat] or floating widget.

== Installation ==
1. Upload the `nyyo-docs-chatbot` folder to `/wp-content/plugins/`
2. Activate the plugin
3. Settings → Nyyo Chatbot → set Bot URL
4. Place [nyyo_docs_chat] on a page, or enable Auto-inject
