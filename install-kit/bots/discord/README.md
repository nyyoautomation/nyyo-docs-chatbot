# Discord bot template (free)

**Free install kit included.**

1. Discord Developer Portal → New Application → Bot → copy token
2. OAuth2 → invite with `applications.commands`
3. `npm i` && `export DISCORD_BOT_TOKEN=... DISCORD_CLIENT_ID=...`
4. `node bot_template.js`
5. In a server: `/docs` → gets your chatbot link

In-channel Q&A with your indexed docs: wired at handover (**free**).
