# Slack app template (free)

**Free install kit included.**

1. api.slack.com/apps → Create New App → From a manifest → paste `manifest.json`
2. Install to workspace
3. Slash command `/nyyo-docs` — point Request URL to your small webhook (we provide a Cloudflare Worker / n8n endpoint at handover, free) that replies with your chatbot URL

Full in-Slack modal UI: **on request (free)** with the package.
