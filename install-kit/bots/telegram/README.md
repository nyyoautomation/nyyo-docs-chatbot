# Telegram bot template (free)

**Free install kit included.** Token stays in **your** BotFather account.

1. Create a bot with @BotFather
2. `export TELEGRAM_BOT_TOKEN=...`
3. `pip install python-telegram-bot==21.6`
4. `python bot_template.py`

Deep RAG inside Telegram (same BM25/index as the web demo) is wired at handover — also **free** with the package.
